# Contact Card App
## Project Overview
A simple Android app developed using Kotlin and XML for the Veda Technology Android Development Track (Day 28). It displays a contact card with user details and provides buttons to trigger implicit intents for calling and emailing.
## Technologies Used
- Kotlin
- XML Layouts
- Android Studio
## Features
- Structured Contact Card UI using CardView
- Call button triggering the phone dialer
- Email button triggering the email client
## How to Run
1. Clone the repository. 2. Open in Android Studio. 3. Sync Gradle. 4. Run the app.
## Outcome
The application successfully displays a well-structured contact card and handles click events using Implicit Intents.
